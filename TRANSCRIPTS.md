# Исправление текста аудиозаписи

В панели проверки нажатие на предложение открывает поле редактирования
текста конкретного голосового и устанавливает курсор в поле.
«Видзны» сохраняет текст, не меняя статус проверки. Затем запись можно принять
обычной кнопкой «Лӧсялӧ». Исправлять можно также уже принятые и отклонённые записи.
Исходная фраза остаётся в базе фраз; при отличии она видна под исправленным текстом.
CSV экспортирует исправленный текст в прежнюю колонку `text`.

## Обновление существующего сервера

Из каталога проекта после `git pull --ff-only`:

```bash
docker compose exec -T web php tools/migrate-transcripts.php
docker compose restart web
```

Миграция добавляет nullable-поле `recordings.transcript`, не меняя существующие
записи. Повторный запуск допустим. Применить перед открытием новой панели или
экспорта; без поля новая панель и CSV не работают. Для новой базы поле уже есть
в `schema.sql`. Старые миграции повторно запускать не требуется.

При одновременном редактировании устаревшая форма не перезапишет чужой текст:
сервер вернёт конфликт. Пустые и превышающие размер TEXT значения отклоняются.
Откат к старому коду не требует удаления нового поля (но старый экспорт не
учитывает исправления).
